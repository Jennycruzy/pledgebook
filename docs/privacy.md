# Privacy notes

The demo guest list contains invented names. The owner's recordings are real
human speech and are kept outside the repository in local ignored evidence.
The application stores only the event details, guest fields supplied by the
organiser, pledge text, and the short audio evidence needed to review a line.

Follow-up contact must use an explicit consent field. Paystack Test Mode is
enabled only when the server has its local test key; no live payment key is
used. Event audio should be removed after the event according to the
organiser's retention choice; the deployment checklist must set that policy
before a live event.

The product does not claim to understand Nigerian Pidgin, Igbo, or Yoruba.
It uses the surrounding English speech only to find names and amounts and
shows a human question when that is not enough.
